## V1. 관계에 따라 달라지는 같은 색

- 삽입 위치: `## 1. 색은 고르는 것이 아니라 관계를 세우는 것이다`
- 삽입 코드: `![[Assets/color-01-context-contrast.svg|720]]`
- 캡션 초안: 같은 파랑도 주변 명도와 채도에 따라 떠오르거나 가라앉는다.

```text
색채 이론 칼럼용 가로형 3패널 도해를 만든다. 세 패널 모두 중앙의 작은 사각형 색은 완전히 동일한 파랑으로 유지한다. 왼쪽 패널은 어두운 배경과 저채도 주변색 위에 놓아 파랑이 밝게 떠오르게 한다. 가운데 패널은 중간 명도 회색과 비슷한 채도의 주변색 위에 놓아 존재감이 줄어들게 한다. 오른쪽 패널은 밝은 노랑과 고채도 주변색 옆에 놓아 파랑이 상대적으로 눌려 보이게 한다. 설명용 라벨은 최소화하고, 디자인은 평면 도해 스타일로 정리한다. 텍스트는 넣지 않거나 최대한 적게 넣고, 독자가 한눈에 '같은 색인데 다르게 보인다'를 이해하게 만든다.
```

## V2. HSB 값과 지각명도의 차이

- 삽입 위치: `## 2. HSB의 숫자와 눈이 느끼는 밝기는 다르다`
- 삽입 코드: `![[Assets/color-02-perceived-lightness.svg|720]]`
- 캡션 초안: 같은 Brightness 값이어도 노랑은 뜨고, 보라는 가라앉는다.

```text
색채 이론 칼럼용 비교 차트를 만든다. 위 줄에는 같은 Brightness 값을 가진 노랑, 연두, 빨강, 파랑, 보라 샘플을 동일 크기 칩으로 배치한다. 아래 줄에는 그 샘플들을 흑백으로 변환한 결과를 대응시켜 배치한다. 노랑과 연두는 더 밝게, 보라와 남색은 더 어둡게 느껴지는 차이가 분명히 읽혀야 한다. 화면은 깔끔한 교육용 인포그래픽 스타일로 만들고, 라벨은 색 이름 또는 간단한 B값 표기 정도만 허용한다.
```

## V3. 주조색, 보조색, 강조색의 비율

- 삽입 위치: `## 4. 주조색, 보조색, 강조색: 비율이 색의 질서를 만든다`
- 삽입 코드: `![[Assets/color-03-color-ratio-layout.svg|720]]`
- 캡션 초안: 같은 색 조합도 면적 배분이 달라지면 질서가 달라진다.

```text
색채 이론 칼럼용 레이아웃 비교 도해를 만든다. 왼쪽에는 주조색 75퍼센트, 보조색 20퍼센트, 강조색 5퍼센트 정도로 정리된 안정적인 구성을 보여준다. 오른쪽에는 강조색 비율이 지나치게 커져 시선이 분산되는 불안정한 구성을 보여준다. 두 예시는 같은 색 세트를 사용하되 면적 비율만 다르게 설계한다. UI 시안처럼 보이되 특정 브랜드나 앱을 연상시키지 않는 중립적인 박스 레이아웃으로 만든다.
```

## V4. 흑백 전환으로 보는 명도 구조

- 삽입 위치: `## 5. 흑백으로 보면 색의 실패가 보인다`
- 삽입 코드: `![[Assets/color-04-grayscale-check.svg|720]]`
- 캡션 초안: 컬러가 그럴듯해 보여도 흑백에서 무너지면 구조가 먼저 흔들린 것이다.

```text
색채 이론 칼럼용 전후 비교 이미지를 만든다. 왼쪽은 여러 색이 섞인 간단한 장면이나 추상 구성이며, 오른쪽은 그 장면의 흑백 변환본이다. 좋은 예시 하나와 나쁜 예시 하나가 동시에 비교되면 더 좋다. 좋은 예시는 흑백에서도 초점과 전경-배경 분리가 분명하고, 나쁜 예시는 모든 영역이 비슷한 회색으로 뭉개져 초점이 흐려지게 만든다. 복잡한 디테일보다는 명도 대비가 읽히는 구조 중심으로 설계한다.
```

## V5. 죽은 회색을 피하는 그라데이션 경로

- 삽입 위치: `## 8. 그라데이션: 죽은 회색을 피하는 색의 경로`
- 삽입 코드: `![[Assets/color-05-gradient-path.svg|720]]`
- 캡션 초안: 보색을 직선으로 잇는 것보다, 경유색을 설계하는 쪽이 자연스럽다.

```text
색채 이론 칼럼용 그라데이션 비교 도해를 만든다. 왼쪽에는 주황에서 파랑으로 직선 보간한 결과를 보여주고, 중간에 탁한 회갈색 또는 죽은 회색이 나타나게 한다. 오른쪽에는 노랑 또는 청록을 경유하는 우회 경로를 따라 더 선명하고 자연스럽게 이어지는 그라데이션을 보여준다. 가능하면 위쪽에는 색상환의 경로 선을 간단히 표시하고, 아래쪽에는 실제 그라데이션 바를 배치해 경로와 결과가 연결되어 읽히게 만든다.
```

## V6. 빛 표현의 네 층위

- 삽입 위치: `## 9. 빛나는 색: 발광, 글로우, 블룸, 그리고 장면에 남는 빛`
- 삽입 코드: `![[Assets/color-06-light-layers.svg|720]]`
- 캡션 초안: 빛은 밝은 물체 하나로 끝나지 않고, 주변에 남는 반응까지 포함해야 완성된다.

```text
색채 이론 칼럼용 4패널 분해 도해를 만든다. 공통 소재는 어두운 공간 속 파란 발광체 하나로 통일한다. 첫 패널은 emission만, 둘째는 emission과 glow, 셋째는 bloom까지, 넷째는 벽과 바닥과 주변 물체에 파란 반사광과 림라이트가 남는 scene lighting influence까지 보여준다. 패널이 오른쪽으로 갈수록 빛의 설득력이 강해지는 구조여야 한다. 과도한 사진 질감보다 개념이 분명한 세미-리얼 또는 그래픽 하이브리드 스타일이 적합하다.
```
