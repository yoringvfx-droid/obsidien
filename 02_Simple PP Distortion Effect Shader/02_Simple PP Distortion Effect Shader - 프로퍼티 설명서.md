# 02_Simple PP Distortion Effect Shader - 프로퍼티 설명서

## Main Texture
- 역할: 왜곡 패턴 소스
- 영향 위치: 그룹 3, 그룹 7
- 실질적 의미: 알베도보다는 왜곡 벡터/마스크 원본
- 이식 팁: 컬러 정보보다 채널 패턴이 중요

## Main Texture Offset Intensity
- 역할: 메인 텍스처 UV 스크롤 양
- 영향 위치: 그룹 2
- 값이 커질수록: 패턴 이동이 빨라지거나 크게 이동
- 제거 가능 여부: 정적 왜곡이면 제거 가능

## Distortion Intensity
- 역할: 전체 왜곡 세기
- 영향 위치: 그룹 4
- 값이 커질수록: 화면 오프셋 증가
- 실무 팁: 다른 프로젝트에서 가장 먼저 노출할 메인 프로퍼티

## Distortion Alpha Range
- 역할: 알파 커브의 범위 제어
- 영향 위치: 그룹 7의 `Remap -> Smoothstep`
- 값이 바뀌면: 표시 범위와 페이드 느낌이 달라짐

## Mask Texture
- 역할: 별도 알파/영역 제한 텍스처
- 영향 위치: 그룹 7
- 이식 팁: 외곽 제어가 필요 없으면 제거 가능

## Mask Intensity
- 역할: 마스크 영향도 배율
- 영향 위치: 그룹 7
- 값이 커질수록: 마스크의 차단/강조 효과가 커짐

## Emission Intensity
- 역할: 최종 색상 밝기 배율
- 영향 위치: 그룹 6
- 주의: 이름은 `Emission` 이지만 실제로는 `Base Color` 마감 배율에 가까움

## Color Mode
- 역할: 컬러 유지 / 그레이스케일 전환
- 영향 위치: 그룹 6
- 구현 방식: `Dot Product` 로 그레이스케일 생성 후 키워드 선택

## Distortion Type
- 역할: 왜곡 소스 생성 방식 선택
- 영향 위치: 그룹 3
- 타입
  - `Type01`: 메인 텍스처 샘플 직접 사용
  - `Type02`: 노말 변환 기반
  - `Type03`: 샘플에 `R` 채널 가중 적용

## Vertex Color
- 역할: 왜곡 강도, 컬러 마감, 알파 제어에 모두 개입
- 영향 위치: 그룹 4, 그룹 6, 그룹 7
- 핵심 채널
  - `A`: 왜곡/알파 강도
  - `RGBA`: 최종 색상 곱

## _GrabPassTransparent
- 역할: 화면 샘플 원본
- 영향 위치: 그룹 5
- 이식 팁: 프로젝트 렌더 파이프라인에서 동등한 화면 텍스처로 대체해야 함
