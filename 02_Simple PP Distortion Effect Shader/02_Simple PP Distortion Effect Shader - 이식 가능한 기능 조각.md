# 02_Simple PP Distortion Effect Shader - 이식 가능한 기능 조각

## 1. 스크린 디스토션 코어
### 목적
- 화면을 왜곡해서 굴절처럼 보이게 만들기

### 필요 그룹
- 그룹 3. 왜곡 소스 생성
- 그룹 4. 왜곡 강도 적용
- 그룹 5. 화면 샘플링 디스토션

### 필수 입력
- `Main Texture`
- `_GrabPassTransparent` 또는 동등한 화면 텍스처
- `Distortion Intensity`

### 선택 입력
- `Vertex Color A`

### 제거 가능 요소
- `Color Mode`
- `Mask Texture`
- `Time` 기반 UV 애니메이션

### 추천 상황
- 가장 작은 단위의 포스트 왜곡 이식

## 2. 움직이는 왜곡 패턴
### 목적
- 왜곡 자체가 시간에 따라 흐르도록 만들기

### 필요 그룹
- 그룹 2
- 그룹 3

### 필수 입력
- `Main Texture Offset Intensity`
- `Time`

### 의존성
- 최종 화면 왜곡으로 쓰려면 그룹 4, 5와 결합 필요

### 추천 상황
- 열기류, 마법, 에너지막

## 3. 노말 기반 왜곡 생성기
### 목적
- 텍스처를 노말처럼 해석해서 더 전형적인 왜곡 벡터를 만들기

### 필요 그룹
- 그룹 3 중 `Normal From Texture` 경로

### 필수 입력
- `Main Texture`
- UV 입력

### 제거 가능 요소
- `Distortion Type`
타입 선택이 필요 없으면 `Type02` 경로만 고정

### 추천 상황
- 가장 안정적인 범용 디스토션 재사용

## 4. 그레이스케일 후처리 옵션
### 목적
- 왜곡된 화면색을 흑백으로 변형

### 필요 그룹
- 그룹 6 중 `Dot Product -> Color Mode`

### 필수 입력
- 왜곡된 화면 색상

### 의존성
- 화면 샘플링 결과가 먼저 있어야 함

### 추천 상황
- 특수 연출, 저채도 디스토션

## 5. 알파 마스크 제어 모듈
### 목적
- 효과가 보이는 영역과 페이드를 독립적으로 제어

### 필요 그룹
- 그룹 7

### 필수 입력
- `Mask Texture`
- `Mask Intensity`
- `Distortion Alpha Range`

### 선택 입력
- `Vertex Color A`
- 메인 텍스처 `R`

### 추천 상황
- 외곽 제어가 중요한 이펙트
- 다른 셰이더의 알파 라인만 개선하고 싶을 때

## 6. 버텍스 알파 강도 제어
### 목적
- 메시별로 왜곡/알파 세기를 미세 조정

### 필요 그룹
- 그룹 4 일부
- 그룹 7 일부

### 필수 입력
- `Vertex Color`

### 제거 가능 요소
- 버텍스 컬러가 없는 파이프라인이라면 상수값으로 교체 가능

### 추천 상황
- 이펙트 메시 제어가 중요한 프로젝트

## 의존성 요약
| 기능 조각 | 단독 사용 | 같이 필요한 것 |
|---|---|---|

| 움직이는 왜곡 패턴 | 불완전 | 왜곡 코어 |
| 노말 기반 왜곡 생성기 | 가능 | 최종 사용처 필요 |
