# 지원 종료일 — End of Support

> [!abstract] 한 줄
> 오래된 컴퓨터 안에 사는 OS 아가씨들이 유저님의 기억을 지키려고 싸운다. 그런데 싸워서 이길수록 업데이트가 진행되고, 업데이트가 끝나는 날은 자기들이 지워지는 날이다.

- **장르** · OS 의인화(OS-tan) 계열 서브컬처 미소녀 내러티브 + 쿼터뷰 액션
- **톤** · 일상 코미디로 밝게 시작해서, 적의 정체와 '지원 종료일'이 드러나며 절망적으로 무거워진다. 마지막에 작은 희망 하나를 남긴다.
- **플레이** · 이펙트 아레나의 **스토리 모드**. 챕터마다 캐릭터(무기)가 정해져 있고, 웨이브를 막은 뒤 보스와 싸운다.
- **원칙** · 실제 OS 이름·로고·상표와 기존 OS-tan 캐릭터는 쓰지 않는다. 창(窓)·사과·펭귄·명령줄처럼 **은유만** 쓴 오리지널 캐릭터다.
- **아트** · 1990년대 말–2000년대 초 OS-tan의 분위기를 따른다. 그 시절 컴퓨터의 소품(회색 입체 버튼, 모래시계 커서, 반투명 플라스틱, 플로피 디스크, 풍선 도움말)을 옷과 장신구에 녹인다. 그림체는 90년대 말 TV 애니메이션 풍이다. 큰 눈과 큰 눈동자 하이라이트, 가늘고 깨끗한 선, 2단 셀 음영, 맑은 원색이 특징이다.

## 세계관

### 호스트 — 컴퓨터 한 대 안의 세계

유저님의 오래된 컴퓨터 한 대가 세계 전체다. 이 컴퓨터는 여러 OS가 함께 깔린 멀티부팅 기기라서, OS 아가씨 여럿이 같은 하드를 나눠 쓰며 산다.

| 장소 | 실제 대응 | 분위기 | 등장 챕터 |
| --- | --- | --- | --- |
| 메모리 광장 | RAM | 푸른 회색 광장. 늘 붐빈다 | 1 |
| 레지스트리 숲 | 설정 저장소 | 어둡고 축축한 초록 숲. 길을 잃기 쉽다 | 2 |
| 바탕화면 갤러리 | 바탕화면 | 밝고 하얀 전시장. 아이콘이 너무 많다 | 3 |
| 휴지통 | 휴지통 | 갈색 어둠. 지워진 줄 알았던 것들이 쌓여 있다 | 4 |
| 업데이트 회랑 | 설치 화면 | 끝없이 하얀 공간 | 5 |
| 펭귄 파티션 | 다른 OS의 영역 | 업데이트가 닿지 않는 곳 | 엔딩 |

### 용어

| 용어 | 뜻 |
| --- | --- |
| **유저님** | 이 컴퓨터의 주인. 화면에 나오지 않고, 입력창에 치는 글(`> …`)로만 말한다 |
| **데이터 코어** | 유저님의 기억(사진·편지·세이브 파일)이 모인 결정. 부서지면 전부 사라지고 세계는 파란 화면으로 끝난다 |
| **버그 · 좀비 프로세스 · 멀웨어** | 코어를 갉아먹는 적. 처음에는 그냥 해충처럼 보인다 |
| **레거시** | 지원이 끝났는데 지워지기를 거부한 OS의 잔해. 살아남으려고 유저님의 데이터를 먹는다 |
| **지원 종료일 (EOL)** | 업데이트도 보안 패치도 더는 오지 않게 되는 날. 이날부터 OS는 '레거시'가 된다 |
| **업데이트** | 노티가 준비하는 것. 끝나면 새 OS가 설치되고, 옛 OS는 모두 정리된다 |
| **호환성 모드** | 지원 종료일이 지난 OS가 억지로 버티는 상태. 오래 못 간다 |

### 왜 싸우는가 — 목표의 3단 변화

| 단계 | 플레이어가 아는 목표 | 실제 의미 |
| --- | --- | --- |
| 1–2장 | 버그를 처치해 **유저님의 기억(데이터 코어)을 지킨다** | 맞다. 적이 코어를 갉아먹으면 실패한다 |
| 3–4장 | 적이 **레거시**, 즉 지원이 끝난 옛 OS라는 걸 안다 | 우리가 지우는 건 우리의 미래 모습이다 |
| 5장 | 레거시가 된 동료를 멈춰야 기억을 지킬 수 있다 | 이기면 **업데이트 100%**. 그건 우리 모두의 끝이다 |

화면의 **✓ 업데이트 준비 %** 는 적을 정리할 때마다 오른다. 플레이어의 진척도가 그대로 주인공들의 소멸 카운트다운이다. 아래 칸의 **지원 종료까지 D-????** 는 3장부터 실제 날짜로 바뀐다.

### 조연

- **노티** · 업데이트 도우미. 2000년대 작업 표시줄의 노란 풍선 도움말을 닮은 요정이다. 하늘색 단발에 연노랑 케이프를 두르고 투명한 날개가 있다. 늘 웃고, 존댓말을 쓰고, 문장 끝에 ✓ 를 붙인다. 악의는 없다. "지원이 끝난 건 위험해요. 위험한 건 정리해야죠. 유저님을 위해서요♪" 끄는 옵션은 없다.
- **유저님** · 얼굴도 목소리도 없다. 가끔 입력창에 짧게 친다. "> 아 느려…", "> 오 좀 낫네", 그리고 마지막에 "> ……고마워".

### 줄거리

1. **부팅** · 페네가 상쾌하게 일어나지만 유저님은 컴퓨터가 느리다고 투덜댄다. 노티가 처음 나타나 버그가 유저님의 기억을 갉아먹는다고 알린다. 메모리를 다 먹던 무한 루프를 끊는다. 노티: "업데이트가 아주아주 새로워질 거예요."
2. **응답 없음** · 아델리가 합류한다. 죽였는데도 일어나는 좀비 프로세스는 부모를 잃고 떠도는 아이들이다. 아델리가 좀비들의 중얼거림이 옛날 시스템의 시작음이었다고 말한다. 페네는 기분 탓이라고 웃는다.
3. **깨끗한 화면** · 말루스는 지원 종료일 이야기를 피한다. 보스는 말루스의 이전 버전이었다. 말루스가 진실을 털어놓는다. 지원이 끝나면 레거시가 되고, 레거시는 살아남으려고 데이터를 먹는다. 그리고 자기 날짜는 D-3이다.
4. **휴지통** · 프롬의 지원 종료일은 10년 전에 지났다. 옛 짝꿍을 직접 포맷한 뒤 호환성 모드가 다한다. "레거시가 되면 나는 코어를 먹으러 간다. 그때는 망설이지 말고 쳐라." 페네는 재부팅하면 된다고 외치지만, 프롬은 "재부팅해도 날짜는 안 바뀐다"는 말을 남기고 응답 없음이 된다.
5. **마지막 업데이트** · 노티가 업데이트가 끝나면 옛 OS는 모두 정리된다고 웃으며 말한다. 말루스: "우리가 버그를 지울 때마다, 우리 차례가 가까워진 거야." 아델리는 업데이트를 멈추려 하지만 권한이 없다. 페네는 레거시가 된 프롬에게서 유저님의 기억을 지키기로 하고 창문을 마지막으로 연다.

### 엔딩

레거시 프롬은 "……잘했다"를 남기고 사라지고, 업데이트가 100%가 된다. 페네는 마지막으로 유저님의 사진 폴더를 업데이트가 닿지 않는 아델리의 파티션에 백업하고 메모를 남긴다.

- 다시 시작하는 중… → 새로운 OS가 설치되었습니다. → 모든 것이 빠르고, 안전하고, 새롭습니다.
- `adelie://home/backup/fene_memo.txt`
- 메모: "유저님께. 그동안 저희를 써 주셔서 고마웠어요. 사진이랑 편지는 아델리 언니 쪽에 잘 넣어 뒀어요. 가끔 느려서 미안했어요. 그래도 유저님 화면 속에서, 우리는 정말 즐거웠어요. — 페네, 말루스, 프롬"
- `> ……고마워`

## 이펙트 연출과의 연결

이 게임은 이펙트 아레나 위에 올린 이야기다. 그래서 장면마다 핸드북 원리를 시험하는 자리가 있다.

| 장치 | 연결된 원리 |
| --- | --- |
| 적의 공격과 범위 표시는 모두 빨강 계열 | 적 공격은 다른 색 (원리 탭에서 끄면 비교할 수 있다) |
| 3장은 밝은 바닥, 5장은 하얀 공간 | 밝은 맵에서도 이펙트가 읽히는지. **M** 키로 가독성 모니터 |
| 보스 패턴은 모두 "범위 표시 → 맞히기" | 모으기는 길게, 맞히기는 빠르게 · 범위 표시 |
| 궁극기 카메라 · 클로즈업 인서트 | 임팩트 프레임 · 구도 축 하나로 왕복 |
| 캐릭터마다 색 = 스킬 색 | 램프를 명도 기준으로 (색이 달라도 밸류는 같다) |

## 스탠딩 일러스트

![[tachie/_캐릭터 시트.png]]

- 대화창 위에 2D 스탠딩이 선다. 왼쪽은 그 챕터의 주인공, 오른쪽은 대화 상대이고, 말하는 쪽만 밝아진다.
- 표정은 10가지다: 기본 · 미소 · 웃음 · 슬픔 · 울음 · 놀람 · 화남 · 눈 감음 · 반쯤 감은 눈 · 공허한 눈. 대사마다 표정이 정해져 있다.
  - 예: 노티의 "지원이 끝난 건 위험해요"는 웃던 눈을 뜬 **공허한 눈**이다.
  - 예: 프롬이 무너지는 장면에서 페네는 **울음**이다.
- 보스는 실루엣에 빛나는 눈과 글리치 띠를 붙였다. 레거시라는 정체를 얼굴 없이 보여 주기 위해서다.
- 직접 그린 그림으로 바꾸려면 `tachie` 폴더에 PNG를 넣는다. 방법은 [[tachie/읽어 주세요]]에 있다.
