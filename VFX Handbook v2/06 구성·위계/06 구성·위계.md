# 06 구성·위계 (Composition)

> 여러 형태 중 무엇을 먼저 읽게 할지 정한다.

| ID | 카드 | 한 줄 원리 |
| :--- | :--- | :--- |
| CP01 | [[CP01 형태 위계 1·2·3차\|형태 위계 1·2·3차]] | 1차가 메시지, 2차가 방향·성격, 3차가 질감. 실눈 뜨면 1차만 남아야 한다. |
| CP02 | [[CP02 위계 실패 5유형\|위계 실패 5유형]] | 위계 실패는 다섯 유형이다. 동일 무게 · 1차 부재 · 3차 과부하 · 2차가 1차 모순 · 중요도와 스케일 불일치. |
| CP03 | [[CP03 분할·밀도·디테일 배치\|분할·밀도·디테일 배치]] | 70/30 불균등 분할, 밀도 변화로 휴식 구역. 디테일은 필요한 곳에만. |

| CP05 | [[CP05 게임 비주얼 스택\|게임 비주얼 스택]] | 환경 < 캐릭터 < VFX < UI 순으로 밸류·채도 예산. 깊이별로 대비를 분리한다. |
| CP06 | [[CP06 구도 축 하나로 왕복\|구도 축 하나로 왕복]] | 시전체 ↔ 대상 대각선 하나 위에서 모든 이동을 처리해 시선 경로를 고정한다. |
