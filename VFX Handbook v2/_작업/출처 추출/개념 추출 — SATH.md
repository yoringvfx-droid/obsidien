# 이펙트 아트 개념 추출 (S 계열)

- 출처 표기: 파일명 + 시작 타임스탬프(mm:ss, 대략). 한 행 = 한 개념. 파일이 다르면 비슷해도 각각 기록.
- 장 분류: 형태 / 밸류 / 컬러 / 빛 / 타이밍 / 구성 / 소재별 / 워크플로·검수 / 기타
- 용어 주의: 자막의 "순회색"은 중국어 원문(純度/灰度 추정)의 기계번역으로 보이며 "채도(순도)와 회색 관계"로 해석했다. 모든 해석은 비고에 표시.
- 출처 약칭 없음: 파일명은 아래 5개 이름 그대로 사용.
  - [Sath] Effect Color Theory.ko.srt
  - [Sath] Effect Color Theory_DLC.ko.srt
