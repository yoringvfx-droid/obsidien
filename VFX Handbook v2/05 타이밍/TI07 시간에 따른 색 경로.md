# 시간에 따른 색 경로

> [!abstract] 원리
> **시작 색과 소멸 색을 따로 정하고, 그 사이 경로를 공간 그라디언트처럼 설계한다. 층마다 바뀌는 속도를 다르게 준다.**

## 왜
- 한 이펙트 안의 색 변화가 긴장 → 해소 → 안정이라는 감정 흐름을 만든다.
- 시간 경로의 중간이 탁해지면 설득력이 떨어진다. 불꽃이라면 중심의 밝은 노랑 → 가장자리의 어두운 빨강 → 연기의 검은 회색으로 이어진다.
- 시간에 따른 미세한 색 변화는 숨은색처럼 전체 색 관계를 풍성하게 한다.

## 규칙
- 터질 때의 색과 사라질 때의 색을 따로 정한다.
- 기본 흐름: 임팩트 = 순수 고채도 최대 강도, 중간 감쇠 = 더 어둡고 차분한 톤, 소산 = 저채도.
- 색상이 크게 바뀌는 전환은 색상환을 돌아가는 경로로 잇는다([[CO08 그라디언트 경로]]).
- 층마다 시차를 둔다. 어두운 층이 먼저 예고하고, 밝은 층이 빠르게 뒤집고, 어두운 층이 천천히 마무리한다.

## 실측 근거
- 바디 색상: 215°(F128) → 240°(F131) → 256°(F132) → 269°(F133) → 281°(F135) → 296°(F140). 보라를 지나 81° 회전하고 회색을 지나지 않는다.
- 전환 동안 바디 명도는 70–71로 그대로이고, 눈에 보이는 선명도는 44 → 49(F131) → 71로 계속 오른다. 사면체 결정만 재도 42 → 66. 색 선택기의 HSV S(채도)는 중간에 0.35까지 떨어져 보이지만 실제로는 탁해지지 않는다(숫자 착시, [[VA02 숫자 ≠ 지각명도]]). (정정: 星光啊 闪爆他 재측정 · BD24)

| 층 | 전환 구간(10–90%) | 길이 | 특징 |
| --- | --- | --- | --- |
| 엣지 | F123–140 | 18f | 가장 먼저 시작, 가장 늦게 끝 |
| 바디 | F128–137 | 10f | |
| 코어 | F129–134 | 6f | 가장 빠르게 뒤집힘 |

- 전파 순서: 테더 끝(시전체 쪽, F122–123) → 사면체 결정 코어(F129–134) → 사면체 결정 바디 → 시전체 구체(F134–140).

## 충돌·주의
- 출처마다 감쇠 방향이 다르다. Color Language 노트는 감쇠 구간을 더 차갑고 어두운 톤으로, 칼럼은 불꽃을 따뜻한 계열 안에서 어두워지다 무채색이 되는 경로로 설명한다. 실측의 잔여 안개는 활성 상태(296–300°)보다 붉은 쪽(322°)이고 밸류가 낮다.
- → 이 핸드북의 정리: 색상 방향은 소재의 의미로 정한다. 공통 규칙은 감쇠할수록 밸류와 채도가 내려간다는 것이다.
