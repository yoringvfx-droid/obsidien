# 05 타이밍 (Timing)

> 같은 형태도 언제, 얼마나 오래 보여주느냐로 힘이 달라진다. 이번 v2에서 새로 만든 장이다.

[[VFX Handbook v2|← 목차]] · [[체크리스트]]

| ID   | 카드                                            | 한 줄 원리                                                                |
| :--- | :-------------------------------------------- | :-------------------------------------------------------------------- |
| TI01 | [[TI01 시간적 위계\|시간적 위계]]                       | 예비 → 임팩트 → 소멸. 가장 중요한 순간에 가장 중요한 형태가 최대로 지배한다.                        |
| TI02 | [[TI02 홀드와 스냅\|홀드와 스냅]]                       | 등장과 퇴장은 빠르게, 키 포즈와 새 형태는 읽힐 만큼 붙잡는다.                                  |
| TI03 | [[TI03 모으기는 길게, 맞히기는 빠르게\|모으기는 길게, 맞히기는 빠르게]] | 기대는 길게 쌓고 한 번에 짧게 갚는다. 같은 공격을 두 번째로 보여줄 때는 모으기를 늘리고 타격까지의 시간을 줄인다.    |
| TI04 | [[TI04 피크 앞 밝기 누르기\|피크 앞 밝기 누르기]]                     | 터지기 직전에 밝기를 뺀다. 클라이맥스에 가까울수록 밝기 누르기는 짧고 깊게.                                |
| TI05 | [[TI05 리듬 — 반복과 압축\|리듬 — 반복과 압축]]             | 같은 문법을 반복하며 키우고, 피크 사이 간격을 좁혀 끝에서 몰아친다.                               |
| TI06 | [[TI06 임팩트 프레임\|임팩트 프레임]]                     | 최대 타격 순간에는 색을 빼고 흑/백 극단 밸류만 남긴 프레임을 1–5장 끼운다.                         |
| TI07 | [[TI07 시간에 따른 색 경로\|시간에 따른 색 경로]]             | 시작 색과 소멸 색을 따로 정하고, 그 사이 경로를 공간 그라디언트처럼 설계한다. 층마다 바뀌는 속도를 다르게 준다.     |
| TI08 | [[TI08 소멸과 여운\|소멸과 여운]]                       | 클라이맥스 뒤에는 대비를 풀고 밝기 천장을 치운다. 장면 색은 1초 안팎에 돌려놓고, 상태가 바뀌었다는 결과 하나만 남긴다. |
