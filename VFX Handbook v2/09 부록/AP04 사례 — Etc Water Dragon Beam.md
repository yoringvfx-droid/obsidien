# 사례 — Etc Water Dragon Beam

> [!abstract] 원리
> **실측 분해 사례. 물 용의 입에서 화면 끝까지 빔을 뽑아 반시계로 휩쓴다. 물은 투명한 막, 하드한 안쪽 결, 하늘빛 코어로 읽힌다.**
> 레퍼런스 영상(GIF) 「Etc Water Dragon Beam」을 프레임 단위로 분해한 결과다.

## 왜
- GIF 585×331, 79프레임, 3.27s다. 프레임 시간이 30ms · 50ms로 번갈아 평균 24fps로 읽는다. 256색 압축 때문에 명도·선명도는 ±2–3 오차다.
- 제목은 RefVault 항목 이름 기준이다. 오른쪽 아래 워터마크 CGWOLD.COM은 재게시 사이트라 작가가 아니다.
- 바닥은 연못 청록(180°, 명도 32)과 돌바닥(129°, 명도 52)이다. 코어 하늘(194°), 바디 파랑(206°), 금색 강조(39°)가 주요 색이다.
- 밝기 단계는 코어 명도 85–100, 바디 60–85, 엣지 35–60, 헤이즈 22–35로 나눈다.
- 끝나는 장면은 GIF에 없다. F1은 빔 없는 용머리 1f로, 루프 앞 프레임으로 본다.

| 2막 발사 | F7–18 | 12f, 0.50s | F7에 빔이 한 번에 화면 끝까지, 강도 최대. 수평 유지 |
| 3막 휩쓸기 | F19–48 | 30f, 1.25s | 오른쪽 위로 반시계 회전, 끝이 기둥 위를 지나며 물보라(F31–36) |
| 4막 상승 | F49–79 | 31f, 1.29s | 위로 서고 왼쪽 위로 기운다. 시전체를 물 돔이 감싼다(GIF 끝) |

핵심 원리 6줄
1. 속성 · 물: 효과 픽셀의 50.4%가 명도 변화 8 미만으로 색만 바뀌는 투명 막이다. 안쪽 흐름선(8.3)이 윤곽(3.7)보다 2.3배 또렷하다(WDB-4, WDB-14).
2. 구도: 73f(3.04s) 동안 빔 끝이 화면 안에 들어온 프레임이 없다. 보이는 길이는 63% → 37% → 27%다(WDB-13, WDB-18).
3. 빔 색: 입 → 끝 명도 66 → 64로 어두워지지 않고, 선명도 26 → 52로 진해진다(WDB-15).
4. 램프: 어두운 끝이 연못 청록(180°)으로 가지 않고 파랑(204°)에 남는다. 램프 전체가 12° 회전 안이다(WDB-6, WDB-7).
5. 코어: 이펙트의 4.0–7.5%, 선명도 13–20의 하늘빛 백색이다. 순백 막은 없다(WDB-3, WDB-9).
6. 강조색: 금색(39°)이 효과 픽셀의 0.3%, 명도 71로 파랑 바디 70과 같다(WDB-10).

총평: 작은 하늘빛 코어, 투명한 막, 같은 명도의 금색 강조는 그대로 가져온다. 파랑에 머무는 어두운 끝과 안쪽 결로 흐름을 보여주는 질감은 조건을 지켜서, 연못 위에서 사라지는 바닥 물길과 화면 밖으로 나간 빔 끝은 게임에 맞춰 바꾸고, 화면의 40% 넘게 1.33s 덮는 빔 면적은 그대로 쓰지 않는다.

| 그대로 가져온다 | 바꿔서 가져온다 | 그대로 쓰지 않는다 |
| --- | --- | --- |
| 코어는 이펙트의 5–6%, 선명도 13–20의 하늘빛 백색 (WDB-3, WDB-9) | 어두운 끝을 환경색 대신 소재색에: 바닥과 같은 계열일 때만 (WDB-7) | 화면 40% 넘게 32f(1.33s) 덮는 빔 + 바닥 물길 (WDB-16) |
| 효과 픽셀 절반을 명도 그대로 색만 바꾸는 투명 막으로 (WDB-4) | 윤곽 대신 안쪽 결로 흐름: 끝이 화면 밖인 빔일 때 (WDB-14) |  |
| 강조색은 바디와 같은 명도, 면적 1% 아래 (WDB-10) | 연못 위 바닥 물길에 명도 45 안팎의 밝은 테두리 (WDB-17) |  |
|  | 빔 끝을 사거리 안에서 보이게, 끝에 하드한 물보라 고리 (WDB-18) |  |
