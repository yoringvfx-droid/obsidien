# 유형별 관습표

> [!abstract] 원리
> **치유·투사체·폭발·실드·독 등 유형별 형태·색·엣지 관습.**
> 유형을 정한 뒤 1차 형태를 고를 때 대조하는 표다.

## 왜
- 이펙트 유형마다 굳어진 형태 관습이 있다.
- 색은 게임 상태 변화를 가장 빠르게 알리는 수단이다.
- 유형별 추천 1차 형태, 엣지, 위계 팁이 정리되어 있어 한 표로 모으면 바로 대조할 수 있다.

## 규칙

| 유형 | 지배 형태 | 엣지 | 색 | 위계 팁 | 개념 ID |
| --- | --- | --- | --- | --- | --- |
| 치유 / 버프 | 원, 부드러운 타원. 치유는 플러스 기호, 위로 올라가는 곡선 | 소프트 | 치유: 초록, 소프트 화이트, 따뜻한 금. 버프: 따뜻한 글로우, 금, 밝은 흰색 | 닫힌 안전 구역이 먼저 읽히게 한다. 중심 광량은 약간 높이고 가장자리는 부드럽게 | L17, L151, L153, L209 |
| 직접 피해 / 공격 | 각진 형태, 뾰족한 폭발, 가시, 삼각형, 각진 방향 표시 | 하드. 바깥으로 터지고 안쪽은 압축 | - | 중심 타격부를 크게, 파편은 작게 | L151, L153, L209 |
| 투사체 | 선, 길게 늘어난 삼각형(쐐기). 방향은 동심으로 수렴하는 선, 진행 방향에 수직인 각진 스파크 | 하드 리딩 / 소프트 트레일 | - | 머리가 1차, 트레일이 2차 | L151, L153, L209 |
| 폭발 | 방사형 원 + 들쭉날쭉한 림 | 하드 코어 / 소프트 연기. 충격파는 질서, 연기는 혼돈 | - | - | L153 |
| 실드 / 배리어 | 원, 반구, 돔, 닫힌 원, 블록 | 하드 림 + 소프트 내부 광 | - | 림은 선명하게, 내부는 보조 정보로 | L151, L153, L209 |
| 독 / 저주(타락) | 유기적 방울, 비대칭, 불규칙한 유기 덩어리 | 소프트, 불규칙. 아래로 흐름 | 병든 초록, 보라, 어두움 | 완전한 노이즈 대신 큰 덩어리를 유지한다 | L17, L153, L209 |
| 어둠 / 공허 | 불규칙한 각진 형태 + 유기적 혼합 | 하드 균열 / 소프트 공허 | - | - | L153 |
| 불 | 유기적 혀 모양 + 위쪽 테이퍼 | 하드 끝 / 소프트 연기 | 적주황 ~ 붉은 불씨 ~ 흰색 | 끝(tip)이 먼저 읽히게 한다 | L17, L153, L209 |
| 번개 | 들쭉날쭉한 불규칙 선(직선이 아님) | 하드, 즉각적 | - | 번개가 지나간 길(strike path)이 먼저 읽히게 한다 | L153, L209 |
| 얼음 | 각진 결정 | 하드, 기하학적 | 청백, 탈채도된 차가움 | - | L17, L153 |
| 성스러움 | 원 + 수직 기둥 | 하드 림 / 소프트 내부 | - | - | L153 |
| 구역 차단 | 경고 기하 | 날카로운 경계 엣지 | 붉은색 | - | L151 |
| 치명타 | - | - | 흰색 또는 순색으로 플래시 | - | L17 |
| 디버프 | - | - | 탈채도, 보라, 황록 | - | L17 |
| 죽음 / 소멸 | - | - | 기존 색의 탈채도와 암화 | - | L17 |

- 빈 칸(-)은 출처에 해당 항목이 없다는 뜻이다.
- 치유와 독은 색이 겹친다(초록). 색이 같으면 형태로 구분한다. 치유는 원과 소프트 엣지, 독은 유기적 방울과 비대칭이다([[CO02 색 언어와 접근성]]).

## 체크
- [ ] 이 이펙트 유형의 1차 형태와 엣지 유형이 표와 맞는가.
- [ ] 치유와 독처럼 색이 겹치는 유형이 형태로 구분되는가.
- [ ] 표에 적힌 1차 부위(머리, 끝, 림, 중심 타격부)가 가장 먼저 읽히는가.
