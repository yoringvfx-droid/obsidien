# 사례 — 放晴 Heart Projectile Burst

> [!abstract] 원리
> **실측 분해 사례. 하트 네 발을 크게 돌려 모으고, 면적을 접고 밝기를 뺀 뒤 수직으로 꽂는다.**
> 레퍼런스 영상 「放晴 Heart Projectile Burst」를 프레임 단위로 분해한 결과다.

## 왜
- 영상은 4.85초, 291프레임, 60fps다. 프레임 수는 30fps 사례([[AP02 사례 — 星光啊 闪爆他]])의 2배로 읽는다.
- 제목은 파일명 기준이다. 放晴는 화면 우하단 워터마크와 같은 이름이라 작가명일 수 있다.
- 바닥은 남색(226°)이고 명도 16.3이다. 하트 핑크(352°), 코어 노랑(55°), 헤이즈 자주(338°)가 주요 색이다.
- 밝기 단계는 코어 명도 85–100, 바디 60–85, 엣지 35–60, 헤이즈 22–35로 나눈다.
- F87–123에 녹화 드롭으로 복제된 프레임이 10장 있다(±1f). 대상이 쓰러지는 F124–175는 면적·단계 비율 오차가 크다.

## 규칙

| --- | --- | --- | --- |
| 1막 발사 | F1–75 | 75f, 1.25s | 하트 투사체 4발 발사(F22 · F39 · F65 · F94), 크게 돌아 대상 쪽으로 |
| 2막 수렴 | F76–123 | 48f, 0.80s | 착탄 섬광, 남은 하트가 세 방향에서 한 점으로 모인다 |

| 4막 낙하 | F183–232 | 50f, 0.83s | 하트 형성 8f · 홀드 24f · 수축 7f → 수직 빔 4f → 슬램 |
| 5막 만개·여운 | F233–291 | 59f, 0.98s | 면적 접기 5f → 만개 돔 → 검은 하트 → 소산, 장면 색 복귀 |

핵심 원리 6줄
1. 타이밍: 슬램 앞 7f(0.12s) 동안 면적을 접고 마지막 3f(0.05s)에 밝기를 뺀다. 강도는 슬램의 6%다(HEART-3, HEART-4).
2. 타이밍: 같은 하트를 두 번 쓴다. 모으기 0f → 39f(0.65s), 맞히기 54f(0.90s) → 4f(0.07s)다(HEART-1, HEART-2).
3. 여운: 슬램 42f(0.70s) 뒤 장면 색상이 보라 285° → 남색 231°로 돌아온다(HEART-14).
4. 색 램프: 노랑 55° → 빨강 5° → 진분홍 354° → 자주 338°. 어두운 끝이 바닥 남색(226°) 쪽으로 기운다(HEART-10, HEART-11).
5. 백색 온도: 발사 코어는 선명도 0의 순백, 대상 위 섬광 코어는 선명도 19–25의 노란 백색이다(HEART-13).
6. 형태: 크게 도는 곡선으로 모으고 수직 빔 하나로 끝낸다. 하트 모티프가 5번 반복된다(HEART-16, HEART-18).

총평: 슬램 앞 누르기, 39f 모으기 → 4f 맞히기, 0.7초 장면 복귀는 그대로 가져온다. 국소 섬광과 백색 온도 구분은 조건을 지켜서, 길이와 바닥 밝기 전제는 게임에 맞춰 바꾸고, 대상을 0.3초 가리는 만개 돔은 그대로 쓰지 않는다.

| 그대로 가져온다 | 바꿔서 가져온다 | 그대로 쓰지 않는다 |
| --- | --- | --- |
| 최대 타격 직전 면적 축소 7f + 밝기 누르기 3f (HEART-3) | 화면 반전 대신 국소 섬광(전환 면적 6%), 직전 누르기와 함께일 때만 (HEART-19) | 대상 실루엣을 17f(0.28s) 30% 넘게 덮는 슬램·만개 (HEART-21) |
| 모으기 39f(0.65s) 중 24f 정지 홀드, 맞히기 4f 직선 (HEART-1, HEART-2) | 백색 온도로 역할 나누기: 발사 선명도 0, 타격 19–25 (HEART-13) |  |
| 슬램 뒤 0.7s 안에 장면 색·최상위 밝기 복귀 (HEART-14) | 발사 → 최대 타격 3.40s를 궁극기 예산 3s 안으로 (HEART-20) |  |
|  | 헤이즈 명도 26–30은 바닥 명도 16 전제, 게임 바닥에 맞춰 올린다 (HEART-22) |  |
