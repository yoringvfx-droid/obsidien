# 02 밸류 (Value)

> 밝기 위계가 시선을 정한다. 색보다 먼저 설계한다.

[[VFX Handbook v2|← 목차]] · [[체크리스트]]

| ID | 카드 | 한 줄 원리 |
| :--- | :--- | :--- |
| VA01 | [[VA01 대비의 크기가 시선을 정한다\|대비의 크기가 시선을 정한다]] | 시선은 대비의 크기가 가장 큰 곳으로 간다. 밝은 쪽이 이기는지 어두운 쪽이 이기는지는 상관없다. |
| VA02 | [[VA02 숫자 ≠ 지각명도\|숫자 ≠ 지각명도]] | HSB의 B(밝기 값)가 같아도 지각명도(L*)는 다르다. 노랑·연두는 뜨고 보라·남색은 가라앉는다. |
| VA03 | [[VA03 명도 구조가 색보다 먼저\|명도 구조가 색보다 먼저]] | 색이 이상하면 원인은 대부분 흑백이다. 지각명도(L*)의 회색 단계를 먼저 정하고 배색한다. |
| VA04 | [[VA04 밸류 단계 설계\|밸류 단계 설계]] | 밸류를 코어·바디·엣지·헤이즈 4단으로 설계하고 키-필 비율로 분리량을 정한다. 변화는 한 구역에 몰아(크런칭) 탁함을 없앤다. |
| VA05 | [[VA05 밝은 면적은 희소하게\|밝은 면적은 희소하게]] | 높은 대비를 넓은 면적에 펼치면 시선이 앉을 곳이 없다. 가장 밝은 코어는 소수 면적에만 둔다. |
| VA06 | [[VA06 색이 바뀌어도 밸류는 고정\|색이 바뀌어도 밸류는 고정]] | 상태 변화는 색상만 바꾸고 단계별 지각명도(L*)는 유지한다. 같은 물체의 다른 상태로 읽힌다. |
| VA07 | [[VA07 대비 전쟁과 주목 양보\|대비 전쟁과 주목 양보]] | 화면에 동시에 있는 이펙트는 대비를 두고 경쟁한다. 둘이 함께 밝으면 지속 요소가 밝기를 낮춰 주인공을 하나로 만든다. |
