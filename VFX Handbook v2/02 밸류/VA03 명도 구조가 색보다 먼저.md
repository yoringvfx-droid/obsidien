# 명도 구조가 색보다 먼저

> [!abstract] 원리
> **색이 이상하면 원인은 대부분 흑백이다. 지각명도(L*)의 회색 단계를 먼저 정하고 배색한다.**

## 왜
- 명암 구조가 무너지면 어떤 색을 올려도 해결되지 않는다.
- 이펙트가 겹친 화면, 광원이 교차하는 장면, 캐릭터와 배경 색조가 비슷한 장면은 색상 차이만으로 분리하기 어렵다. 명도 위계가 정리해 준다.
- 색도 명암도 대비로 생긴다. 회색이 받쳐 주지 않으면 색이 살아나지 않고, 화면 전체가 다 세면 과자극이 된다.

## 규칙
- 순서는 색 추출 → 대비·명암·회색 단계 결정 → 색을 풍성하게 만들기다.
- 그림처럼 명도 구조를 먼저 깔고 화면을 만든다. 어둠을 방치하지 않게 된다.
- 슬라이더를 조정한 뒤 흑백으로 바꿔 실제 명암 구조를 확인한다. 색을 올리기 전과 후에 한 번씩 본다.
- 흑백에서는 초점, 전경·배경 분리, 시선 흐름을 본다. 모든 영역이 비슷한 회색으로 뭉개지면 명도 설계 문제다.
- 안쪽 레이어 분리가 좋아도 아래쪽이 터지거나 밝은 부분이 과하면 흑백 관계가 흐트러진다.
- 배색 다음에는 명암 대비와 채도·회색 관계를 따로 정한다(자막 번역 불확실: "순회색"을 채도와 회색 관계로 해석).
