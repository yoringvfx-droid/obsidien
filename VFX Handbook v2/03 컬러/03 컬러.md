# 03 컬러 (Color)

> 팔레트는 색 하나가 아니라 밝기에 따라 색상이 움직이는 램프다.

[[VFX Handbook v2|← 목차]] · [[체크리스트]]

| ID | 카드 | 한 줄 원리 |
| :--- | :--- | :--- |
| CO01 | [[CO01 색은 관계다\|색은 관계다]] | 같은 색도 주변에 따라 뜨고 가라앉는다. 색을 바꾸기보다 주변을 바꾸는 편이 빠르다. |
| CO02 | [[CO02 색 언어와 접근성\|색 언어와 접근성]] | 색은 인지 이전에 감정을 만든다. 온도·채도·색상 연상으로 말하되 문화 차이를 고려하고, 색 단독 의존은 금지한다. |
| CO03 | [[CO03 역할과 비율\|역할과 비율]] | 색마다 역할을 준다. 주조·보조·강조 순으로 면적을 나누고, 강조는 희소해야 힘이 있다. 평균 배분은 금지한다. |
| CO04 | [[CO04 조화 유형과 색 수\|조화 유형과 색 수]] | 조화 유형(유사·보색·분할보색·사색)은 후보를 좁히는 도구다. 색상 계열은 2–3개(최대 5개)로 제한하고, 추출한 배색은 그대로 쓰지 않는다. |
| CO05 | [[CO05 채도 위계\|채도 위계]] | 채도는 필요한 곳에만 세운다. 탁함은 회색의 양이 아니라 대비의 부재에서 온다. |
| CO06 | [[CO06 램프 — 밝기 따라 색상 이동\|램프 — 밝기 따라 색상 이동]] | 밝은 쪽은 노랑·시안·자홍 쪽, 어두운 쪽은 파랑·빨강 쪽으로 색상을 튼다. 어두운 끝은 환경색으로 수렴한다. |
| CO07 | [[CO07 숨은색\|숨은색]] | 흑백 값이 같은 다른 색상을 섞어 튀지 않으면서 풍부하게 만든다. 강한 색은 디테일에만 쓴다. |
| CO08 | [[CO08 그라디언트 경로\|그라디언트 경로]] | 보색을 직선으로 보간하면 중간이 죽은 회색이 된다. 색상환을 돌아가는 경로로 잇고, 그라디언트는 필요한 만큼만 쓴다. |
| CO09 | [[CO09 코어는 색을 품은 백색\|코어는 색을 품은 백색]] | 가장 밝은 곳은 채도를 낮춘 백색, 가장 진한 색은 바로 바깥의 바디에 둔다. 순백은 클라이맥스용으로 아낀다. |
