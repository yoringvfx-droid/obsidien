# 조화 유형과 색 수

> [!abstract] 원리
> **조화 유형(유사·보색·분할보색·사색)은 후보를 좁히는 도구다. 색상 계열은 2–3개(최대 5개)로 제한하고, 추출한 배색은 그대로 쓰지 않는다.**

## 왜
- 색을 더할수록 내부 경쟁만 늘어 가독성이 떨어진다. 적은 색상과 큰 명도 변화가 효과적이다.
- 배색 공식은 얼마나, 어디에, 어떤 명도·채도로 쓸지를 정해 주지 않는다. 보색을 50:50으로 나누면 시각적 소란이 되고, 유사색 세 개를 균등하게 쓰면 밋밋해진다.
- 배색은 평균화되기 쉽다.

## 규칙
- 색상 계열은 2–3개, 최대 5개로 둔다.
- 배색 추출 사이트의 삼색·사색·유사색·유사 사색 모드로 후보를 먼저 확보한다. 사색은 보색 두 쌍이라 이펙트의 기본 배색을 뽑기에 좋다.
- 사색에서 한 색을 빼 3색 기본 배색을 만들고 포인트 보색 하나를 더하는 공식이 가장 단순하다(자막 번역 불확실: 더하는 보색이 어느 색인지 불분명).
- 추출한 배색을 그대로 쓰지 않는다. 채도(순도)·색 비율·명암을 다시 손본다(자막 번역 불확실: "순회색"을 채도와 회색 관계로 해석).
- 황록 계열은 다루기 어렵다. 가능하면 빨강이나 파랑 쪽으로 붙인다. 어두운 노랑·초록은 노란 편향을 줄여 오렌지 쪽으로 보내면 색이 살아난다(화자도 많이 시험하진 않았다고 단서).
- 최종 판단은 공식 밖에서, 화면 위 관계로 한다.

| 유형 | 특징 | 적합한 곳 |
| --- | --- | --- |
| 유사색 | 인접 색상(유사 사색 포함). 같은 계열 배색감, 단일 온도의 응집·연속감, 내부 대비 낮음 | 앰비언트·지속형 |
| 보색 | 반대편 색상. 최대 색상 대비, 낮은 불투명도·작은 크기에서도 튐 | 임팩트 순간·코어 하이라이트·초점 강조 |
| 분할보색 | 주색 + 보색 양옆 두 색. 보색 대비를 얻되 거칠지 않고 변화가 더 있음 | 마법·특수능력 |
| 삼각 | 엄격한 명도 통제 없이는 압도적. 유사+삼각 변형으로 제한 | 제한적으로만 |
| 사색 | 보색 두 쌍 | 기본 배색 추출 |

## 충돌·주의
- Palette LIT 인용(Shahrabi)은 가장 효과적인 장면의 색상을 1–3개(최대 5개)로 보고, 같은 노트의 요약과 구축 워크플로는 2–3개로 쓴다. → 이 핸드북의 정리: 색상 계열은 2–3개, 최대 5개로 통일한다.
