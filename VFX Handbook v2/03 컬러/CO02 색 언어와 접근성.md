# 색 언어와 접근성

> [!abstract] 원리
> **색은 인지 이전에 감정을 만든다. 온도·채도·색상 연상으로 말하되 문화 차이를 고려하고, 색 단독 의존은 금지한다.**

## 왜
- 플레이어가 디테일을 처리하기 전에 색이 감정 반응을 만든다.
- 색 언어는 분위기·톤(심미/감정)과 위험·치유·진영·상태(기능/소통)를 동시에 말해야 한다.
- 팔레트 전체의 성격이 정서를 정한다. 치유 주문이 빨강·주황이면 위협으로 읽힌다.

## 규칙
- 온도는 다이얼이다. 다른 요소를 고정하고 따뜻한 쪽에서 차가운 쪽으로 옮기기만 해도 감정이 바뀐다. 따뜻함은 에너지·긴박, 차가움은 차분·거리·신비를 전한다.
- 채도는 감정 신호의 강도를 정한다(표 2). 색상은 두고 채도만 빼면 형태를 바꾸지 않고 손상이나 죽음을 전달한다.
- 색상 연상은 학습된 감정 어휘다(표 1).
- 표 1은 서구·글로벌 시장 관습이다. 빨강은 동아시아에서 행운, 흰색은 일부 아시아에서 애도를 뜻한다.
- 위험 신호는 색에만 맡기지 않고 형태·움직임·소리·밝기 대비·텍스처로 보강한다. 색각 이상은 남성 플레이어 약 8%다. 적록색약(deuteranopia/protanopia) 시뮬레이션으로 검수한다.
- 제한된 팔레트는 테마를 이펙트와 UI 전체에 인코딩하고, 색 변화는 서사를 예고한다(예: BioShock Infinite).

표 1. 색상 연상

| 색상 | 연상 | 용례 |
| --- | --- | --- |
| 빨강 | 위험·열정 | 불·피·어그로 |
| 주황 | 에너지·모험 | 폭발·버프 |
| 노랑 | 기쁨·주의 | 번개·성스러운 빛·파워업 |
| 초록 | 성장·안전·치유·독 | 힐·자연 마법·독 |
| 파랑 | 차분·신뢰·냉기·정밀 | 얼음·물·실드·SF |
| 보라 | 신비·럭셔리·초자연·타락 | 저주·엘리트 |
| 흰색 | 순수·신성·정화 | |
| 검정 | 힘·공허·죽음 | |

표 2. 채도와 팔레트 성격

| 채도·팔레트 | 읽히는 정서 |
| --- | --- |
| 고채도 | 긴박·강렬·스타일화 |
| 중채도 | 읽힘·현존 |
| 저채도 | 침울·낡음·비강조 |
| 무채색 근접 | 공포 위험·배경 중립·퇴색·소멸 |
| 따뜻함 + 고채도 | 에너지·공격 |
| 차가움 + 저채도 | 차분·깊이 |
| 전 구간 고채도 | 흥분·마법·스타일화 |
| 저채도 팔레트 | 분위기·부패·섬세 |
| 따뜻한 코어 + 차가운 가장자리 | 마법 에너지·초자연적 열 |

## 충돌·주의
- Color Language 노트는 온도 축에서 치유를 차가운 색 쪽에 두고, 같은 노트의 상태 표는 치유에 초록·흰색·따뜻한 금을 쓴다. → 이 핸드북의 정리: 치유는 "초록 + 따뜻한 하이라이트"로 표기한다. 독도 초록 계열이므로 독과는 형태로 구분한다.
