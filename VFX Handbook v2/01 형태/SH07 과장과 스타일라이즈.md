# 과장과 스타일라이즈

> [!abstract] 원리
> **단순화한 뒤 증폭한다. 형태 언어가 과장 방향을 정하고, 레이어마다 과장 우선순위가 다르다.**
> 과장은 메커니즘이고 스타일은 의도다. 둘은 분리할 수 없다.

## 왜
- 현실은 느리고 모호하며 노이즈로 가득하다. 과장(exaggeration)은 노이즈를 걷어 신호를 증폭한다. 필요한 이유는 표 A에 있다.
- 스타일라이제이션(stylization)은 알아볼 수 있음을 유지하며 시각 특징을 단순화·각색해 표현력과 고유성을 높이는 일이다. 과장 위에서 살아난다.
- 포토리얼 게임도 과장한다(God of War, The Last of Us, Ghost of Tsushima). 차이는 정도이고, 스타일별 수준은 표 D에 있다.

## 규칙
- 먼저 본질 형태로 줄인다. 불=위로 가늘어지는 형태, 폭발=바깥으로 확장되는 구, 베기=빠른 호다. 그다음 더 크고·빠르고·공격적이고·휘고·들쭉날쭉하게 민다. 맥락 없이도 의도가 전달될 때까지 민다.
- 마이크로 디테일을 줄인다. 복잡성은 과장의 적이다.
- 증폭 방향은 형태 언어가 정한다(표 B).
- 스케일과 비율도 민다. 현실 크기의 검 베기는 스타일라이즈드에서 2–3배가 필요할 수 있다. 파이어볼은 이동 방향으로 늘이고 수직 방향은 압축한다.
- 레이어마다 우선순위가 다르다(표 C). 연기 같은 하위 레이어를 과장하면 코어보다 드라마틱해져 읽히지 않는다.
- 정도는 아트 디렉션에 맞추고 몰입이 유지되는 경계 바로 안쪽에서 멈춘다(표 D, E).
- 시작은 현실 참고, 검증은 프리미티브 블로킹이다. 불기둥=원기둥, 폭발=임팩트에서 찌그러진 구, 베기=절단선을 훨씬 넘어 뻗는 리본으로 블로킹한다. 의도가 전달되면 방향이 맞고, 모호하면 더 과장한다.

**표 A. 과장이 필요한 이유**

| 이유 | 내용 |
| --- | --- |
| 게임플레이 속도 | 1초 미만에 처리된다 |
| 카메라 거리 | 10m 이상이면 사실적 디테일이 붕괴한다 |
| 시각적 경쟁 | 대담한 형태가 이긴다 |
| 감정적 명확성 | 들쭉날쭉=폭력성, 둥근=무해, 확장되는 폭발=힘 |

**표 B. 형태 언어별 과장 방향**

| 형태 언어 | 과장 방향 |
| --- | --- |
| 원·둥근 | 전체 부피를 키우고 모든 엣지를 부드럽게 |
| 날카로운·들쭉날쭉 | 경계를 뾰족하게, 코어를 좁히고, 표면을 파편화 |
| 흐르는 곡선 | 길게 늘이고 루프를 만들어 중심에서 멀리, 리본처럼 |
| 각진·대각선 | 움직임 벡터 쪽으로 강하게 기울이고 이동 방향으로 늘림 |
| 확장 방사형 | 경계 레이어를 코어보다 불균형하게 멀리 밀어냄 |

**표 C. 레이어별 과장 우선순위**

| 레이어 | 과장 우선순위 |
| --- | --- |
| 코어·임팩트 중심 | 최대 |
| 1차 이미터 형태 | 높음(특징적 실루엣) |
| 2차 디테일 파티클 | 중간(1차와 경쟁 금지) |
| 배경 대기감 | 낮음 또는 없음 |

**표 D. 스타일 스펙트럼**

| 스타일 | 형태 접근 | 과장 수준 |
| --- | --- | --- |
| 포토리얼 | 물리 정확 | 없음·숨김 |
| 세미 리얼 | 명확성을 위해 밀어붙임 | 낮음~중간 |
| 스타일라이즈드 리얼 | (원문 미기재) | 중간 |
| 완전 스타일라이즈드 | 대담한 형태 언어 | 높음 |
| 셀 셰이딩·애니메 | 2D 기반, 플립북 중심 | 매우 높음 |
| 카툰 | 단순 프리미티브, squash & stretch | 극단적 |

**표 E. 과장 정도의 신호**

| 구분 | 신호 |
| --- | --- |
| 부족 | 게임플레이 거리에서 약하다. 의도가 오독되거나 노이즈로 무시된다. 환경에 섞인다 |
| 과함 | 게임 시각 언어에서 벗어난다. 정보보다 산만하다. 의미적 연결을 잃는다 |

**표 F. 실패 모드와 수정**

| 증상 | 원인 | 수정 |
| --- | --- | --- |
| 의도 없이 무작위처럼 느껴짐 | 형태 언어 미정의 | 특징 형태를 찾아 일관되게 증폭 |
| 게임 안에서 동떨어져 보임 | 아트 디렉션 불일치 | 게임의 시각 언어를 연구해 보정 |
| 형태 정체성을 잃음 | 과도한 추상화 | 현실 참조 "접지" 형태 하나를 유지 |
| 스타일라이즈드인데 약하게 읽힘 | 디테일 과강조 | 2차를 덜어내고 코어가 지배 |
| 이펙트가 모두 비슷해 보임 | 유형 차별화 부재 | 디테일 전에 유형별 고유 특징 형태 부여 |
