# 형태 언어 사전

> [!abstract] 원리
> **원=안전, 사각=안정, 삼각=위험, 유기=혼돈. 날카로울수록 험악하다.**
> 뇌는 텍스처보다 먼저, 때로는 애니메이션보다 먼저 형태를 읽는다.

## 왜
- 형태 언어(shape language)는 색·디테일·애니메이션이 처리되기 전에 기하·유기 형태로 감정·의도·게임플레이 의미를 전달한다.
- 모든 파티클 경계, 폭발 윤곽, 트레일 호가 신호다. 이펙트 제작은 사용할 기본 형태를 정하는 데서 시작한다.
- Blizzard 디자인 시스템은 역할을 형태로 나눈다. 힐러=원, 탱커=사각형, 딜러=삼각형이다.

## 규칙
- 이펙트의 게임플레이 역할에 맞는 형태 계열을 아래 표에서 먼저 고른다.
- 날카로운 끝은 자연에서 위협의 서명(발톱·송곳니·가시·칼날)이다. 날카로울수록 험악하고, 뒤집힌 삼각형은 특히 불안정하다.
- 각짐의 정도로 의미를 조절한다. 길게 늘어난 약한 각짐=속도·방향, 여러 가시=공격성·위협, 극도로 불규칙한 가시=타락·어둠의 마법·혼돈이다.
- 원과 곡선에는 날카로운 모서리와 방향성 위협이 없다. 뇌가 분석 전에 안전한 것으로 읽는다.
- 불규칙 형태는 무질서로 마음에 부담을 주어 감정을 불편·불안·두려움 쪽으로 기울인다. 의도된 불규칙이어야 한다(노이즈와의 구분은 SH04).

![[shape-language-spectrum.svg|640]]

| 형태 | 기본 읽기 | 대표 사용처 |
| --- | --- | --- |
| 원·곡선 | 안전·보호·회복·수용 | 치유·지원 오라, 실드·배리어, 버프(부드러운 타원), 안전 구역 표시 |
| 사각·직사각 | 안정·무게·방어·구조 | 탱커 능력, 요새화·방어 배리어, 지면 기반 플랫폼 |
| 삼각·각진·날카로움 | 위험·공격성·통증·속도 | 피해 주문·공격 능력, 빌런 능력, 투사체 방향 스파크, 임팩트 경계의 들쭉날쭉한 림 |
| 불규칙·유기 | 혼돈·부패·자연성·미지 | 어둠·공허·타락, 독·부패·강령술, 불·연기·물, 환경 앰비언트(낮은 혼돈도) |
| 수평 | 안정·휴식·고요 | 지면 강타·충격파(강력하지만 덜 위협적), 수평으로 퍼지는 치유 오라 |
| 수직 | 위엄·힘·영속성·상승 | 부활·성장·상승 빔, 수직 임팩트 기둥 |
| 선·대각선 | 속도·방향·집중·정밀 | 투사체, 빔, 베기 트레일, 테더(SH03 참조) |

## 실측 근거
- 레퍼런스 영상은 서사 단계마다 형태 계열을 바꾼다. 14단계 형태 흐름은 다음과 같다.

| 서사 | 형태 계열 | 프레임 |
| --- | --- | --- |
| 모으기 | 곡선 | 초승달 F24 · 원+십자 F38 · 갈고리 혜성 F52 |
| 맞히기 | 방사 | 방사 가시 F66(시안 가시와 짙은 남색 파편이 섞여 폭발 내부에도 명도 대비) |
| 가두기 | 기하 | 삼각 문양 F90 · 사면체 F110 |
| 잇기·모으기2 | 유기 | 물결 테더 F127 · 내부 삼각 파편 F155 · 불규칙 리본 F206 |
| 끝내기 | 직선 | 수평 스트릭 F212 · 직선 빔 F221 |
| 타격 | 방사 | 반전 버스트 F226 · 유리 파편 F232 |
| 흔적 | 삼각(데칼) | 그을린 삼각 데칼 F252 |

- 방사 계열은 맞히기(F66)와 타격(F226)에 두 번 쓰인다.

## 충돌·주의
- Shape Language 노트는 원을 안전·보호로 읽고 비위협적이라고 적는다. Exaggeration 노트 표는 원/둥근 형태를 "안전, 힘, 완결성"으로, 본문은 "둥근 형태=무해함"으로 적는다. → 이 핸드북의 정리: 원의 기본 읽기는 안전·보호(무해)다. "힘"은 Exaggeration 노트가 병기한 읽기로 두고 분류 기준으로 쓰지 않는다. 힘을 전할 때는 수직 형태(위엄·힘·영속성)나 사각형(안정·힘)을 쓴다.
