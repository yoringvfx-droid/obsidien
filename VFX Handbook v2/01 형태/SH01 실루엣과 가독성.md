# 실루엣과 가독성

> [!abstract] 원리
> **색·질감을 다 빼도 1초 안에 무엇인지 읽혀야 한다. 거리·각도·속도 조건에서.**
> 실루엣(silhouette)은 색·텍스처·조명이 사라진 뒤 남는 순수한 형태이고, 플레이어의 첫 번째 언어다.

## 왜
- 가독성(readability)은 기능 요구사항이다. 실루엣으로 읽히지 않으면 게임 상태를 전달하는 임무를 실패한 것이다.
- 에디터에서 선명한 이펙트도 실제 플레이 조건을 견뎌야 한다. 실루엣은 이 조건을 통과할 가능성이 가장 높은 레이어다.
- 기준은 게임 거리·움직임·혼란한 화면에서 1초 이내에 무슨 일인지 아는 것이다.

## 규칙
- 실제 플레이 조건에서 확인한다(표 A). 이 조건에서 많은 디테일이 사라진다.
- 단순한 큰 형태가 복잡한 큰 형태보다 빠르게 읽힌다. 복잡성은 2·3차 레이어에 두고 1차 실루엣 경계에는 두지 않는다.
- 가장 중요한 행동 요소가 실루엣 우선권을 갖는다. 액션 라인은 하나로 설명되어야 하고, 디테일은 중심부·포인트에 몰고, 빈 공간으로 형태를 분리한다.
- 360도 문제: 게임 유형별 핵심 카메라 각도 2–3개(TPS 후방, 사이드 스크롤 프로필, 탑다운)에서 반드시 빛나게 한다. 나머지 각도에서는 완벽하지 않아도 작동하게 한다.
- 대각선 질량 분리: 레이어를 완전한 수직·수평으로 정렬하지 않고 대각선으로 분리해 실루엣에서 합쳐지는 것을 막는다.
- 사실성과 가독성이 부딪치면 가독성을 택한다. 큰 shape가 먼저 읽히지 않으면 미세 파티클·노이즈·텍스처는 방해물이다.
- 요구 수준은 게임플레이 중요도로 정한다(표 B).

**표 A. 실제 플레이 조건**

| 조건 | 내용 |
| --- | --- |
| 거리 | 카메라에서 10m 이상 |
| 각도 | 카메라는 아티스트가 아니라 플레이어가 조작 |
| 움직임 | 실루엣이 매 프레임 바뀜 |
| 경쟁 요소 | 적 이펙트·HUD·피격 반응·환경 FX 아래에 묻힘 |
| 속도 | 뇌가 디테일을 처리할 시간이 없음 |

**표 B. 맥락별 요구 수준**

| 이펙트 유형 | 가독성 요구 |
| --- | --- |
| 공격·피해 VFX | 즉시 읽혀야 하며 타협 불가. 움직임 속 15m에서도 전달 |
| 피격 반응 | 절대적 명확성. 몇 프레임 안에 방향 판독 |
| 범위 이펙트 표시 | 명확하고 모호하지 않음 |
| 앰비언트 루프 | 미묘해도 됨 |
| 분위기·환경 효과 | 부드러워도 됨 |

## 실측 근거
- **放晴 Heart Projectile Burst**(60fps): 최대 타격 동안 대상 실루엣 덮음은 아래 충돌·주의에 적었다. ([[放晴 Heart Projectile Burst - Index]] · HEART-21)

## 충돌·주의
- 출처 A(Silhouette 본문)는 기준 거리를 카메라에서 10m 이상으로 적는다. 출처 B(Silhouette 맥락별 표)는 공격·피해 VFX를 움직임 속 15m로 적는다. → 이 핸드북의 정리: 중요도별 기준으로 쓴다. 일반 이펙트는 10m, 공격·피해는 15m다.
- 게임 적용 주의: 放晴 Heart Projectile Burst의 최대 타격 F226–243 18f(0.30s) 중 17f(0.28s) 동안 이펙트가 대상 실루엣을 30% 넘게 덮는다. 최대는 F226의 94.5%다 → 대응: 만개 돔 가운데를 바디 단계(명도 60–85)로 비워, 30%를 넘는 구간을 연속 3f(0.05s) 이하로 줄인다. ([[放晴 Heart Projectile Burst - Index]] · HEART-21)
- 게임 적용 주의: Etc Water Dragon Beam은 빔 끝이 화면 안에 보인 프레임이 0 / 73f(3.04s)다. 끝 쪽 밝은 관이 2–6%로 가늘어지며 사라진다 → 대응: 사거리 끝에 하드한 물보라 고리(명도 85 이상, 이펙트의 2% 안팎)를 두고, 끝 2–3%는 관 두께를 줄이지 않는다. ([[Etc Water Dragon Beam - Index]] · WDB-18)

## 체크
- [ ] 단색 검정으로 칠해도 10m(공격·피해는 15m)에서 무엇인지 읽히는가?
- [ ] 핵심 카메라 각도 2–3개에서 덩어리가 하나로 합쳐지지 않는가?
- [ ] 큰 형태가 먼저 읽히는가? 디테일을 지워도 의미가 남는가?
