# 01 형태 (Shape)

> 무엇을 먼저 말할지 정하고, 멀리서도 읽히게 만든다.

[[VFX Handbook v2|← 목차]] · [[체크리스트]]

| ID | 카드 | 한 줄 원리 |
| :--- | :--- | :--- |
| SH01 | [[SH01 실루엣과 가독성\|실루엣과 가독성]] | 색·질감을 다 빼도 1초 안에 무엇인지 읽혀야 한다. 거리·각도·속도 조건에서. |
| SH02 | [[SH02 형태 언어 사전\|형태 언어 사전]] | 원=안전, 사각=안정, 삼각=위험, 유기=혼돈. 날카로울수록 험악하다. |
| SH03 | [[SH03 방향과 선\|방향과 선]] | 대각선=움직임. 선 굵기·직선도가 속도와 결단을 말한다. |
| SH04 | [[SH04 질서와 혼돈\|질서와 혼돈]] | 질서 있는 코어 + 혼돈의 외곽. 질서를 먼저 보여줘야 혼돈이 읽힌다. |
| SH05 | [[SH05 하드·소프트 엣지\|하드·소프트 엣지]] | 닿는 곳은 하드, 남는 곳(트레일·연기)은 소프트. |
| SH06 | [[SH06 네거티브 스페이스\|네거티브 스페이스]] | 덩어리 사이 틈이 있어야 분리되고, 분리되어야 읽힌다. |
| SH07 | [[SH07 과장과 스타일라이즈\|과장과 스타일라이즈]] | 단순화한 뒤 증폭한다. 형태 언어가 과장 방향을 정하고, 레이어마다 과장 우선순위가 다르다. |
| SH08 | [[SH08 모티프와 형태 문법\|모티프와 형태 문법]] | 고유 모티프 1–2개를 끝까지 반복해 정체성과 서사를 만든다. |
