# 04 빛 (Light)

> 밝게 칠하는 것과 빛나 보이는 것은 다르다.

[[VFX Handbook v2|← 목차]] · [[체크리스트]]

| ID | 카드 | 한 줄 원리 |
| :--- | :--- | :--- |
| LI01 | [[LI01 빛의 4층위\|빛의 4층위]] | 발광 → 글로우 → 블룸 → 장면에 남는 빛. 마지막 층이 설득력을 만든다. |
| LI02 | [[LI02 블룸 — 다리이자 대비 킬러\|블룸 — 다리이자 대비 킬러]] | 블룸은 광원처럼 읽히게 하지만 넓게 쓰면 대비를 죽인다. 좁고 강하게. |
| LI03 | [[LI03 이미시브·HDR·노출\|이미시브·HDR·노출]] | 임계값과 배율로 블룸 자격을 정하고 텍스처 안에 휘도 위계를 둔다. 노출·톤매핑과 같이 본다. |
| LI04 | [[LI04 광감 — 빛은 퍼져야 빛난다\|광감 — 빛은 퍼져야 빛난다]] | 밝은 순색이 퍼지지 못하면 밋밋하다. 점점이 끊긴 빛은 흐름이 없다. |
| LI05 | [[LI05 화면 레벨 장치\|화면 레벨 장치]] | 노출 상승·비네트·아나모픽 스트릭·색수차·반전 인서트. 카메라 대신 밝기가 흔든다. |
