# 증상별 처방표

> [!abstract] 원리
> **뜸·탐·흐림·더러움·회색 치우침·과자극·한 톤·덩어리 실루엣의 원인과 수정.**
> 증상 이름보다 원인을 먼저 가려서 고친다.

## 왜
- 색이 하얗게 뜨거나 타거나 흐리거나 더러워 보이는 문제는 결국 흑백 관계와 채도–회색 관계 두 가지로 귀결된다(자막 번역 불확실: 원문의 "순회색"을 채도–회색 관계로 해석).
- 실루엣 실패는 명도 분리 부족, 경계 파티클 과다, 환경 대비 부족, 일반적인 형태, 텍스처 의존, 요소 간 분리 부족으로 나뉜다.
- 원본에 원인이나 처방이 적혀 있지 않은 칸은 "(원본에 없음)"으로 표시했다.

## 규칙

표 1. 색·밸류 증상

| 증상 | 화면에서 보이는 것 | 원인 | 처방 | 개념 ID |
| --- | --- | --- | --- | --- |
| 뜸 | 밝은 영역이 하얗게 떠 보인다 | 흑백 관계 또는 채도–회색 관계 | 흑백 관계부터 점검한다([[VA03 명도 구조가 색보다 먼저]]). 밝은 부분의 색 보정은 [[CO09 코어는 색을 품은 백색]] | S20 |
| 탐 | 그을린 화면. 적갈색이 아니어도 생긴다 | 완전 검정과 완전 밝음의 대비가 심하다 | 바깥 화면을 단순한 효과로 정리한다(자막 번역 불확실: "CMYK처럼"). 원하는 색을 찍고 필요한 순색만 닦아내듯 살린다. 잘게 부서진 효과를 걷고 중간색으로 검은 구간과 이어 준다 | S20, S58, S59 |
| 흐림 | 전체가 흐릿하다 | 흑백 관계 또는 채도–회색 관계 | 원본은 원인 분류만 제시한다. 처방은 회색 치우침 행을 따른다 | S20 |
| 더러움 | 어두침침하고 혼탁하다. 안료를 여러 색 섞은 듯 답답하고 방향성이 없다 | 특정 구간의 채도와 명도가 모두 너무 낮아 검게 죽는다. 채도만 낮은 경우는 해당하지 않는다 | 죽은 색을 제거한다(배경 죽은 색 행). 어두운 쪽은 순도를 보장한다(어둡게만 내려 검게 죽음 행) | S20, S44 |
| 배경에 죽은 색 | 배경색이 더럽고 산만하다. 구석에 죽은 색이 쌓인다 | (원본에 없음) | 거의 없애고 마지막에 남기지 않는다. 색상이 안 느껴질 정도면 제거한다 | S56 |
| 어둡게만 내려 검게 죽음 | 어두운 쪽이 검게 죽고 밝은 순색이 한 영역에 몰린다 | 색상 조정 없이 어둡게만 내렸다 | 어두운 쪽의 순도를 보장한다. 색상을 먼저 조정한 뒤 어둡게 한다(자막 번역 불확실) | S66 |
| 회색 치우침 | 전체 대비가 낮다. 일부 구역이 검게 죽고 회색이 돌아 갇혀 보인다 | 끌어올릴 색과 대비가 부족하다. 밝아야 할 곳이 안 올라온다. 어두운 쪽 텍스처가 회색에 치우친다 | 밝은 색을 더 과감하게 쓰고 전체 색 대비를 조금 더 강하게 한다. 어두운 쪽 회색 텍스처는 과감히 밝히거나 정리한다. 어두운 쪽 대비는 소량 보강만으로도 힘이 생긴다. 전체가 약간 회색이면 더 밝은 흰 라인을 옆에서 올려 주듯 추가하고 끊기는 검은 띠를 정리한다 | S43, S61, S62, S64, S65 |
| 과자극 | 촌스러운 화면. "불에 너무 구워져 메마른 듯한 폭발감"(현업 속어) | 밝은 쪽도 어두운 쪽도 채도가 너무 높고 대비까지 지나치다 | 원본은 원인만 제시한다. 채도는 필요한 곳에만 세운다([[CO05 채도 위계]]) | S42 |
| 한 톤 | 탈색하면 전부 같은 톤이다. 레이어감과 공간감이 없다 | 명도 층 분리가 없다. 거의 한 색으로 채웠다 | 층을 더한다. 사례에서 거의 한 색이던 바닥 불꽃에 층을 더하자 전체 레이어감과 공간감이 좋아졌다 | S21 |
| 어두운 빨강 단색 | 화면을 받쳐 주지 못한다. 보는 사람이 불편하고 오래 보면 메스꺼울 수 있다 | 어둡고 탁한 빨강 계열 색만 쓴다 | 작은 디테일을 많이 더한다 | S24 |
| 뭉개진 색 | 색이 한데 뭉개진 부분이 있다 | (원본에 없음) | 일부를 흰색 쪽으로 보내 분리한다(자막 번역 불확실: 사례의 대상이 기호 부분인지 불명) | S25 |
| 색 조각이 잘게 흩어짐 | 색 조각이 너무 잘게 흩어져 튄다 | (원본에 없음) | 어느 정도 통일감을 주고 색이 튀지 않게 정리한다 | S57 |
| 딱딱한 면 | 면이 딱딱하게 서 있다 | (원본에 없음) | 힘을 빼고 위로 올리는 색을 더해 약간 여유를 둔다. 너무 다시 메우지 않는다(자막 번역 불확실: "위로 올리는 색"의 의미 불명) | S60 |
| 흑백 관계 깨짐 | 색을 얹은 뒤 흑백 관계가 무너진다 | 그라디언트 맵은 같은 명도 층에 한 색만 대응시켜 흑백 관계를 쉽게 깨뜨린다([[CK04 작업 순서 모음]]) | 레이어를 복사해 오버레이로 놓고 50% 정도만 섞는다. 살짝만 돌려 주면 충분하다 | S39 |

표 2. 실루엣 실패 6유형

| 증상 | 화면에서 보이는 것 | 원인 | 처방 | 개념 ID |
| --- | --- | --- | --- | --- |
| 형태 없는 덩어리 | 이펙트가 형태 없는 덩어리로 읽힌다 | 파티클이 모두 같은 명도이고 위계가 없다 | 코어·중간·외곽 레이어를 서로 다른 명도 범위로 분리한다 | L131 |
| 지저분한 경계 | 경계가 지저분하고 읽히지 않는다 | 경계에 작은 파티클이 너무 많다 | 경계 파티클을 줄이고 리딩 엣지를 깨끗하고 선명하게 만든다 | L131 |
| 배경에서 안 보임 | 배경 위에서 이펙트가 보이지 않는다 | 환경과의 명도 대비가 부족하다 | 코어 밝기를 높이고 림·외곽선 레이어를 추가한다 | L131 |
| 유형 구분 불가 | 형태만 보고 이펙트 유형을 알 수 없다 | 일반적인 형태 언어 | 해당 이펙트 유형의 특징적 형태를 과장한다 | L131 |
| 움직임에서 안 읽힘 | 거리에서는 읽히지만 움직임 속에서는 읽히지 않는다 | 내부 텍스처 디테일에 과도하게 의존한다 | 실루엣을 먼저 설계하고 텍스처는 보너스 레이어로 둔다 | L131 |
| 두 요소 합쳐짐 | 두 요소가 실루엣에서 합쳐진다 | 분리 없이 덩어리들이 겹친다 | 네거티브 스페이스, 대각선 각도, 레이어 간 명도 대비를 추가한다 | L131 |

## 체크
- [ ] 증상을 색 문제로 단정하기 전에 흑백으로 바꿔 보았는가.
- [ ] 처방 뒤에 밝은 곳은 올라오고 어두운 곳은 검게 죽지 않았는가.
- [ ] 실루엣 실패는 색과 텍스처를 뺐을 때도 같은 문제가 남는가.
